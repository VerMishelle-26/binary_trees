\# Бинарные деревья и AVL



Учебный проект по алгоритмам и структурам данных.



\## Что реализовано



1\. \*\*К1\*\* — класс `BinaryTree` с `insert` и `search`.

2\. \*\*К2\*\* — обход в ширину `bfs(root)`.

3\. \*\*К3\*\* — обходы в глубину: `preorder`, `inorder`, `postorder`.

4\. \*\*К4\*\* — класс `AVLTree` с поворотами `left\_rotate`, `right\_rotate` и `rebalance`.



\## Анализ



\### BinaryTree (BST)

\- \*\*Средний случай:\*\* O(log n) для insert/search.

\- \*\*Худший случай:\*\* O(n) — если дерево вырождено в список.



\### BFS

\- \*\*Сложность:\*\* O(n) — каждый узел посещается один раз.

\- \*\*Память:\*\* O(n) — очередь может содержать все узлы уровня.



\### DFS

\- \*\*Preorder:\*\* корень → левое → правое.

\- \*\*Inorder:\*\* левое → корень → правое (даёт отсортированный список для BST).

\- \*\*Postorder:\*\* левое → правое → корень.

\- \*\*Сложность:\*\* O(n).



\### AVLTree

\- \*\*Балансировка:\*\* автоматически при вставке.

\- \*\*Высота:\*\* всегда O(log n).

\- \*\*Повороты:\*\* left\_rotate, right\_rotate.

\- \*\*Сложность:\*\* O(log n) для insert/search.
